# Unity 6 House Simulation Project

Welcome to the **House Simulation Project**! This repository contains a 3D environment prototype built using **Unity 6** and the **Universal Render Pipeline (URP)**. The project explores immersive player interaction and dynamic environmental lighting systems, demonstrating the capabilities of modern Unity development.

## 🎮 Features

### 1. Interactive First-Person Prototype
* **First-Person POV:** Navigate the house from an immersive player perspective.
* **Interactable Elements:** Fully functional doors and toggleable lights with on-screen prompts for seamless user interaction.
* **Furnished Interiors:** Detailed room environments that respond realistically to local and ambient light sources.

### 2. Expanded Environment & Dynamic Lighting
* **Large-Scale Property:** Includes a spacious outdoor sitting area and a custom swimming pool.
* **Drone / Editor POV:** Explore the entire level from an aerial perspective to observe the scale of the map.
* **Runtime Day/Night Cycle:**
  * Dynamically switches between times of day (Sunrise, Noon, Sunset, Night) via a custom UI dropdown.
  * Demonstrates real-time swapping of **baked lightmaps**, **directional lights**, and **skyboxes** to maintain high-quality lighting at any time of day without heavily impacting performance.
